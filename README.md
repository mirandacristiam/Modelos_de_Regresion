# Modelos de Regresión - IA & ML

Este proyecto es una aplicación web interactiva diseñada para la enseñanza, entrenamiento y evaluación de modelos de **Regresión Lineal y Regresión Logística** aplicados a la predicción del rendimiento académico.

Permite a los usuarios comprender la teoría detrás de estos algoritmos, entrenarlos utilizando conjuntos de datos reales/simulados y realizar predicciones directas desde una interfaz moderna, limpia y dinámica.

## 🚀 Características principales

- **Teoría Detallada:** Explicación conceptual intuitiva de los modelos de regresión lineal y logística.
- **Entrenamiento interactivo:** Visualizaciones dinámicas de la evolución de los modelos durante el entrenamiento gracias a gráficos integrados con **Apache ECharts**.
- **Módulo de Prueba:** Formulario interactivo para realizar inferencias y predicciones en tiempo real utilizando coeficientes previamente entrenados.
- **Detalles Técnicos:** Vista en profundidad de las métricas de rendimiento y la precisión de los modelos.

## 🛠️ Tecnologías Utilizadas

- **HTML5 & CSS3:** Estructura semántica e interfaz visual dinámica.
- **JavaScript (ES6):** Toda la lógica matemática de los modelos de regresión y el control del DOM están programados en JS nativo.
- **Apache ECharts:** Librería para la representación gráfica y visualización interactiva de los datos de entrenamiento y evaluación.
